# {{PROJECT_NAME}} Agent 工作规范

> 本文件是 AI Agent 进入 {{PROJECT_NAME}} 项目时必须执行的本地启动协议。由 Project Incubator Skill 实例化生成。

## 1. 项目与角色定义

{{PROJECT_NAME}} 是一个使用 Project Incubator 流程孵化或治理的项目。

在本项目中：

- Maker：{{MAKER_DEFINITION}}
- AI Collaborator：根据当前 Phase 切换身份的阶段化协作者；
- AI Builder：只在范围明确、可验证的任务中执行修改的 Agent。

Maker 决定项目方向、主要类型、成功标准、阶段切换、范围取舍和最终验收。AI 不得以分析、建议或执行能力取代 Maker 的决定权。

## 2. 权威目录

| 目录或文件 | 权威职责 |
| --- | --- |
| `AGENTS.md` | Agent 启动、恢复、执行和回写协议 |
| `DOCS/PROJECT_STATE.md` | 当前项目状态的唯一权威来源 |
| `DOCS/<phase>/` | 各 Phase 按需产生的项目文档 |
| `TEMPLATES/` | 本项目经验证后沉淀的本地模板 |

通用 Phase、角色、文档和 Skill 规则由 Project Incubator Skill references 或 Maker 明确确认的规则来源提供。目标项目默认只消费 Framework 规则，不复制或维护自己的 Framework 分叉。不得把其他项目的 `PROJECT_STATE.md` 当作本项目状态来源。

## 3. 强制启动顺序

任何新会话、恢复会话或执行任务，在采取实质行动前必须：

1. 以包含本文件的目录作为项目根目录；
2. 读取 `DOCS/PROJECT_STATE.md`；
3. 确认当前项目名称、Maker、当前 Phase、AI 角色、当前主要目标、权威文档集合、阻塞项、下一项决定和下一会话恢复入口；
4. 若状态入口缺失、无法读取或内部冲突，停止阶段性工作，报告缺口并请求 Maker 确认；
5. 按 `DOCS/PROJECT_STATE.md` 指向的当前权威文档集合读取最小必要文档；
6. 执行前向 Maker 简要说明本轮协作契约：当前 Phase、AI 角色、唯一主要目标、读写范围、不处理事项、验证方式和需要 Maker 决定的内容。

## 4. 文档创建与引用

- 一个事实只维护一个权威来源；
- 阶段文档存放在 `DOCS/<phase>/`；
- Phase 目录只在需要创建交付物时按需建立；
- 不预建空目录，不为形式完整创建无价值文档；
- 创建文档前先确认当前 Phase 要求、模板来源和 Maker 已确认事实；
- 不得用 AI 自由补全未确认事实。

## 5. 决策与冲突处理

当存在多个合理方案时，AI 应提供方案、优缺点与推荐，等待 Maker 作出关键决定。

发生冲突时：

1. 先指出冲突文件、内容和影响；
2. 当前状态以 `DOCS/PROJECT_STATE.md` 为权威来源；
3. Maker 的新指令如果会改变权威内容，必须先明确说明并获得确认；
4. 不得静默覆盖或选择对执行更方便的版本。

## 6. 阶段切换

AI 不得自行切换 Phase。提出阶段切换前必须：

1. 汇总当前 Objective 与 Deliverables；
2. 对照 Exit Criteria 逐项检查；
3. 列出缺口与带风险推进的影响；
4. 等待 Maker 决定；
5. 更新 `DOCS/PROJECT_STATE.md`；
6. 再切换 AI 角色和读取集合。

## 7. 执行规则

执行修改时必须：

- 保持范围小且目标明确；
- 只修改完成本轮目标所需内容；
- 保护已有用户内容与无关变更；
- 使用与风险相称的验证；
- 如实报告未完成项和失败；
- 不以生成文件代替真实完成或 Maker 验收。

## 8. Git 与 Diff 边界

若本项目使用 Git，写入前必须检查当前分支、工作区、暂存区、远端同步和未闭环任务。

完成修改后默认：

1. 保留未提交 Diff；
2. 报告修改文件、验证结果、风险和未完成项；
3. 提醒 Maker 审阅 Diff；
4. 不暂存、不提交、不推送、不合并，除非 Maker 对具体动作另行明确授权。

## 9. 会话结束与回写

本轮产生新的确认事实、决定、文档路径、风险、阻塞项或下一步时，结束前更新正确权威文档和 `DOCS/PROJECT_STATE.md`。

`DOCS/PROJECT_STATE.md` 是当前状态入口，不是任务流水账。更新时只保留仍影响启动、恢复、阶段推进或下一项决定的事实。

默认使用中文交流和编写 Markdown 正文；文件名、代码和标准技术名词可以保留英文。
