# 状态摘要契约

`inspect_project` 的中文说明固定按以下顺序呈现：

1. 项目目标、支持边界与排除边界；
2. 项目类型、Child Skill、Host Profile、阶段与阶段状态；
3. 最近完成事项及当前证据上限；
4. 当前行动、下一步行动与完成条件；
5. 阻塞与风险；
6. 待 Maker 决策；
7. Capability Evidence、Known-Good Baseline 与人工验证预算；
8. 最近变更、revision 与 Receipt 完整性。

缺失内容必须明确显示“无”“未设置”或“未建立”，不得根据聊天记录推测。`PROJECT_OVERVIEW.md` 只能由同源摘要按需导出，不参与 Gate、Workflow 或状态恢复。
